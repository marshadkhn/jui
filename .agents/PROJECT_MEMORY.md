### Key Architectural Patterns
- **Next.js 16 App Router Structure (`src/app/`)**:
  - `src/app/layout.tsx`: Root shell hosting global providers (`BlackHoleTransitionProvider`, `SmoothScroll`), interactive utilities (`CustomCursor`, `Navbar`, `Footer`), and the persistent 3D canvas (`GlobalModelScene`).
  - `src/app/page.tsx`: Home landing page coordinating hero intro, interactive scroll-triggered product sections, and single-session initial loading sequence (`LoadingScreen`).
  - `src/app/about/page.tsx`: Corporate overview, founding timeline (established 1997 in Mumbai), credential milestones, executive leadership, in-house technical engineering capabilities, and turnkey industrial portfolio.
  - `src/app/card/page.tsx`: Dedicated smart card & secure credential industry showcase driven by `CardHeroSection.tsx` and interactive 3D card models (`Card.tsx`).
  - `src/app/currency/page.tsx`: Currency, banknote, and coin minting solutions featuring `PaperWindMesh` 3D simulation, partner product grids (`PartnerProductsGrid.tsx`), and security printing specifications.
  - `src/app/partners/page.tsx`: Global principal representation portal leveraging `IndiaSection.tsx` and 3D globe visualization (`EarthIndiaSection.tsx`) to map manufacturing partners worldwide.
  - `src/app/contact/page.tsx`: Dual-facility operations guide covering Mumbai Andheri Corporate HQ & Turbhe Works/Warehouse (RT Print Technology), interactive multi-category RFQ portal, and direct sovereign liaison contacts.
- **Unified 3D & Scroll Synchronization**:
  - Single persistent WebGL Canvas via `GlobalModelScene` / `ModelScene` driven by Framer Motion's `useScroll` (`scrollYProgress`) and Lenis smooth inertial scrolling (`src/components/providers/SmoothScroll.tsx`).
  - Custom GLSL Shaders: Volumetric space nebula particle simulation (`NebulaMaterial`), star fields, and atmosphere glows that respond dynamically to scroll depth and viewport drift.
  - Multi-stage Product Carousel (`ProductSections.tsx`): Synchronizes scroll percentage intervals with 3D model transforms (Note Printer, Card Industry Tech, Paint Mixer, interactive India Earth globe).
- **Interactive Earth & Geolocation Coordinates**:
  - `EarthIndiaSection.tsx` & `Earth1Locations.tsx`: Uses equirectangular UV mapping (`u`, `v`) and geographic coordinates (`lat`, `lng`) from `principalsData.ts` to pin partner principal facilities directly onto the 3D globe surface with real-time hover tooltips (`LocationHoverTooltip`) and detail cards (`PrincipalDetailCard`).
- **Asset Pipeline & Optimization**:
  - High-poly CAD GLB models decimate and quantize using Draco (`draco3dgltf`), Meshoptimizer, and GLTF Transform utilities (`scripts/compress_model.py`) to reduce multi-million vertex models into performant web assets.

### Known Gotchas & Constraints
- **Next.js 16 Breaking Changes**: This project runs on Next.js 16.2.2 and React 19.2.4. Review deprecation warnings and reference `node_modules/next/dist/docs/` before implementing Next.js router, font, or configuration features.
- **Client-Side Only 3D Execution**: WebGL/Three.js components (`@react-three/fiber`, `@react-three/drei`) must always run strictly on the client. Dynamic imports must specify `{ ssr: false }` or be wrapped in client boundary checks to avoid `window is not defined` hydration failures during SSR / build.
- **Lenis & Framer Motion Scroll Sync**: Smooth scrolling is managed by Lenis. When adjusting scroll triggers or bounding elements, ensure scroll calculations use the centralized scroll progress motion values rather than raw DOM window scroll events.
- **Tailwind CSS v4 Configuration**: Configured with `@tailwindcss/postcss` and Tailwind v4. CSS variables and theme configurations reside directly in `src/app/globals.css`.
